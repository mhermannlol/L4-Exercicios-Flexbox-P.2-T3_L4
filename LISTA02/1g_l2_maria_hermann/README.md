PARTE B

1. 
eixo principal: é a direção principal onde os flex items são dispostos
eixo cruzado: é o eixo perpendicular ao eixo principal

2. 
os três itens ficarão dispostos em uma única linha horizontal, com uma altura fixa de 200px para o contêiner e tamanho fixo de 80x60px para cada bloco, com fundo azul e texto branco.

haverá um espaçamento uniforme ao redor dos itens e eles estarão perfeitamente centralizados

3. 
row orienta os itens na horizontal, justify-content alinha horizontalmente e align-items alinha verticalmente
column orienta os itens na vertical, justify-content começa a alinhar verticalmente e align-items passa a alinhar horizontalmente

4.
align-items alinha os itens individualmente dentro de sua linha no eixo cruzado
já o align-content alinha as linhas de itens umas em relação as outras quando há multiplas linhas

5.
flex-grow define a capacidade do item de crescer se houver espaço livre
flex-shrink define a capacidade de encolher se o espaço for insuficiente
flex-basis define o tamanho inicial do item antes de distribuir o espaço restante

o item flex: 2 1 200px tem fator de crescimento 2, fator de encolhimento 1, e tamanho base inicial de 200px
